Selected Projects

Contact Center Staffing Planner

Discrete-event simulation · Monte Carlo methods · Domain modeling · Spec-Kit · AI-assisted development

A workforce-management tool that simulates an inbound voice contact center to help determine how many agents are needed, and when, to meet service goals. The project is at an early stage: it currently consists of a detailed domain model covering entities, events, state machines, and metric definitions, which drives spec-driven implementation. Its design records every simulated event so that new metrics can be computed later without re-running the simulation.
